今日の教え方

11枚。同じチャットで会話と作業、できれば Cursor に Claude Code、ポータルの作り方・直し方まで

今日のゴール：同じチャットで社内ポータルの1ページを作り、お知らせを1件足せる。

やらないこと：ポスター、請求書・経費の長い実習。教室は補助。先生が画面を見せて、受講者は同じ文をコピーして貼る。Cursor の Claude Code はできれば。ポータルはチャットでも進む。

一本の話

「相談できる → 作ってもらえる → 直せる」で通す。ポスターと黒い画面は出さない。隣の人との会話や見せ合いはしない。先生の横で、相手の画面を一緒に見る。

  1. チャット入門（相談）
  2. 同じチャットで作業（以前のCoworkはここに入った）
  3. ポータルを作る
  4. ポータルを直す

最初に言うこと：「以前 Cowork として別の場所にあった機能は、今このチャットに統合されています。資料作成も会話も、同じ画面です。別のアプリに切り替えなくてよいです。」

1. チャット入門（15〜20分）

口頭は短く。左が履歴、下が入力欄。教室の「コピー」→ 入力欄をクリック → 貼る → 送る。

実習は1回。「最初のお願い」の見本文を使う。返事が来たら成功。教えるのは「貼って送る」だけ。上手な文章は後回し。

2. 同じチャットで作業（25分）

今日が初めての人が多い。教室の「今日の講義」のまま進む。請求書STEPは飛ばす。

  • claude.ai でもアプリでも同じチャット。同じメールでログイン
  • 新しいチャット。左に Cowork が無くても探さない
  • できること：ページや資料を作る／ファイルを読む／フォルダをつなぐ／同じ会話で直す
  • 見る場所：新しいチャット、会話一覧、入力欄と送る、クリップ、フォルダ、作業中、許可の窓、できた画面、できたリンク、モデル（Opus）、Effort（高め）、トークン（使用量）
  • 今日の決まり：モデルは Opus、Effort は高め（High）。トークンは多めに使う。同じ会話で直す。見つからなければ無理に探さない
  • Gmail・カレンダー・ドライブ（できれば）：つながるとメールの要点・来週の予定・資料探しが楽。教室のお願い文を1つずつ貼る。送る・消すはしない。無ければ飛ばす
  • 「許可しますか」と出たら、今日使うものだけ。全部はいらない

止まりやすいところ：左にCoworkが無い → 探さない。同じチャットで「作って」。インストールできない → 無理に突破しない。新しいチャットまで来たら次へ。

2.5 Cursor に Claude Code（できれば）

cursor.com から入れる。拡張機能で「Claude Code」（Anthropic）。公式 https://code.claude.com/docs/en/vs-code の Install for Cursor。ログインは claude.ai と同じ会社メール。拡張を入れた人も、ターミナルに1行を自分で貼る。教室のコピー → ターミナルをクリック → 貼る → Enter。行頭が % なら Mac（curl の1行）。PS なら Windows（irm の1行）。zsh: command not found: irm は、Mac に Windows を貼った印。会社で止められたら飛ばしてポータルへ。

3. ポータルを作る（35〜45分）

教室の「見本文を貼る」をそのまま使う。自分の言葉に直さなくていい、と言う。

実際の例：社内ポータルの見本（Claudeの成果物）。会社のホームページの例 https://mmiho1505-code.github.io/portfolio/ （チャットで作った外向け。今日作るのは社内ポータル）

TOPは4つ。上からこの順。5つ目は作らない。

  1. お知らせ（新しいものが上、3件まで）
  2. 今月の予定
  3. よく使うリンク（勤怠・メール・フォルダ。出退勤はここのボタン）
  4. 部署の連絡先（名前・内線・メール。携帯は載せない）

待ち時間に復唱：誰が・何を・どんな感じか。

できたページのチェックは4つだけ。並び／社名／リンクが押せるか／スマホで文字が小さすぎないか。リンクをお気に入りに保存。会話は閉じない。

4. 直し方（25〜35分）

  • ページの中を自分でいじらない
  • 作った会話の続きに「〇〇を△△に変えて」
  • 直したら、ページを再読み込み

実習は2つまで。①お知らせを1件、一番上に足す。②内線を1つ変える、またはよく使うリンクに経費精算を足す（［URL］は穴埋め、と先に言う）。失敗したら「元に戻して」。

5. おわり（5分）

覚えて帰ること3つ。

  1. 会話も作業も同じチャット（以前の Cowork はここに入った）
  2. 1ページは4つ。上から お知らせ→予定→リンク→連絡先
  3. 直すときは続きに書く。見てから社員に渡す

載せないもの：パスワード、携帯番号、給与。宿題にするなら「自分の会社の名前に直して、お知らせを1件足す」だけ。

言い方の型

今から先生がやります。同じ文をコピーして、一緒に送ってください。うまくいかなくても、続きに「元に戻して」と書けば大丈夫です。
