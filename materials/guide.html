はじめてのClaude 教室　説明資料（印刷用）

迷ったときの進み方

やりたいことで、道は1本だけ選びます。人気順ではありません。混ぜなくて大丈夫です。

どちらの道か

  • 事務（ファイルまで任せたい） → Claude Cowork　画面で日本語。黒い画面は使いません。
  • 道具（自分の道具をつくりたい） → Claude Code　PowerShell か ターミナルに 1行貼る。

事務の順番

  1. アカウント　claude.ai に入る
  2. チャット　ブラウザで日本語を 1回
  3. ポスター　いちばんやさしい課題
  4. Cowork　請求書・経費などの本番

道具づくりの順番

Windows と Mac は、どちらか一方だけでよいです。

  1. Windows の人は PowerShell　または　Mac の人はターミナル
  2. 最初の道具は投稿文（いちばんかんたん）
  3. つづきはかんたん順　集計 → 経費 → 請求書 → 分析 → サイト → 秘書 → 使いこなし

教室の押し方

  • オレンジのボタンは、タップ（左クリック）
  • 黒い枠の「コピー」→ 自分の画面に貼る
  • ページ下「このページを読んだ」でハンコ
  • 続きはマイページから 1タップ

安全

  • パスワード・口座・マイナンバーは渡さない
  • 送る・消す・公開の前は、自分の目で確認
  • 金額と宛名は指差し確認

困ったとき

つまずき一覧、操作のしかた、チャット。講師（宮田先生）へは、いつもの連絡手段でも送れます。
