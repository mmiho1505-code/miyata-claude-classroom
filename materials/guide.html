はじめてのClaude 教室　説明資料（印刷用）

迷ったときの進み方

やりたいことで、道は1本だけ選びます。人気順ではありません。混ぜなくて大丈夫です。

どちらの道か

  • 事務（ファイルまで任せたい） → 同じチャット　画面で日本語。黒い画面は使いません。以前の Cowork はここに入っています。
  • 道具づくり（自分用のツールを作りたい） → Claude Code　PowerShell／ターミナルに1行

事務の順番

  1. アカウント　claude.ai に入る
  2. 設定　左の一覧（一般・請求・メモリー・コネクタ）。全部いじらなくてよい
  3. チャット　ブラウザで日本語を 1回
  4. ポスター　いちばんやさしい課題
  5. 事務（同じチャット）　請求書・経費などの本番

道具づくりの順番

  1. Node（任意）　必須ではない
  2. Windows は PowerShell、Mac はターミナル
  3. 最初の道具　投稿文
  4. つづきはかんたん順

HTML・CSS・JavaScript

ページは3つでできています。コードは書かなくてよいです。日本語で頼めます。

  • HTML … 骨組み。何が載っているか
  • CSS … 見た目。色・大きさ・並び
  • JavaScript … 動き。押したら変わる。Java（ジャバ）は名前が似ている別の言語です

教室の押し方

  • 紺のボタンは、タップ（左クリック）
  • 黒い枠の右上の「コピー」→ 自分の画面に貼る
  • ページ下「このページを読んだ」でハンコ
  • 続きはマイページから 1タップ

安全

  • パスワード・口座・マイナンバーは渡さない
  • 送る・消す・公開の前は、自分の目で確認
  • 金額と宛名は指差し確認

困ったとき

つまずき一覧、操作のしかた、チャット。講師（宮田先生）へは、いつもの連絡手段でも送れます。
